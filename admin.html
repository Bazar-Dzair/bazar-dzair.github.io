المحظورون

أرقام الهاتف وعناوين IP هذه لا يمكنها تسجيل أي طلب جديد فالمتجر.

🛡️ حماية الطلبات (حظر IP)

كل الطلبات تمر حصرًا عبر Cloudflare Worker الذي يرى عنوان IP الحقيقي ويطبّق الحظر وكشف الإساءة. لا يوجد أي مسار احتياطي للكتابة المباشرة — firestore.rules تمنعها دائمًا، من أي صفحة كانت. لو تعطّل الـ Worker تفشل الطلبات مؤقتًا (يظهر للزبون طلب إعادة المحاولة) بدل أن تُحفظ بلا حماية.

لم يتم فحص الـ Worker بعد.

🌐 عناوين IP المحظورة

يظهر عنوان IP لكل طلب جديد في صفحة الطلبات، ويمكنك حظره بضغطة على زر 🌐. الطلبات القديمة (قبل تفعيل هذه الخاصية) لا تحمل عنوان IP. انتبه: شبكات الهاتف قد تتشارك نفس العنوان بين عدة زبائن، فاستعمل حظر IP للمزعجين المتكررين فقط.

إنذارات الإساءة

يراقب النظام أنماط الطلبات المشبوهة (IP، رقم الهاتف، الجهاز، العنوان) ويسجّل إنذارًا هنا. الإنذار لا يمنع الطلب: القرار لك، احظر الرقم أو الـ IP بعد التأكد.

⚠️ عنوان IP وحده مؤشر ضعيف لأن عدة زبائن قد يتشاركون نفس العنوان (خاصة عبر شبكات الهاتف)؛ لذلك يعطي إنذارًا منخفضًا فقط. الإنذارات المتوسطة والعالية تعتمد على الهاتف أو الجهاز أو العنوان.
